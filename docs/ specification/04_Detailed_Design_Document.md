## 3. 主要処理の詳細ロジック

### 3.1 月次バッチ処理フロー

```
cronトリガー（毎月1日 08:00 JST）
  │
  ▼
① アクティブサイト一覧取得
   SELECT * FROM sites
   WHERE is_active = true
   AND report_start_date <= DATE_TRUNC('month', CURRENT_DATE)
  │
  ▼
② サイトごとにループ処理
  │
  ├─ ③ GA4 APIでデータ取得（前月の指標）
  │
  ├─ ④ HTMLテンプレートにデータを埋め込み
  │
  ├─ ⑤ PuppeteerでHTMLをPDFに変換
  │
  ├─ ⑥ reports テーブルにレコード挿入（status: generated）
  │
  ├─ ⑦ 配信チャネルに応じて送信
  │    ├─ email → Nodemailerで送信
  │    └─ line  → LINE Messaging APIでプッシュ
  │
  └─ ⑧ delivery_logs に結果を記録
         成功 → status: success
         失敗 → status: failed、error_message を記録
                最大3回リトライ（5分間隔）
                最終失敗時 → 管理者にアラートメール送信
```

---

### 3.2 GA4 APIリクエスト仕様

| 項目 | 内容 |
|---|---|
| エンドポイント | `POST https://analyticsdata.googleapis.com/v1beta/properties/{propertyId}:runReport` |
| 認証方式 | サービスアカウント（Application Default Credentials） |
| dateRanges | `[{ startDate: 'YYYY-MM-01', endDate: 'YYYY-MM-{末日}' }]` |
| metrics | `sessions`, `totalUsers`, `screenPageViews`, `bounceRate`, `averageSessionDuration` |
| dimensions | 月次集計のため不要（全期間の合計を取得） |

**レスポンス例**

```json
{
  "rows": [{
    "metricValues": [
      { "value": "1200" },
      { "value": "980" },
      { "value": "3400" },
      { "value": "0.42" },
      { "value": "185.3" }
    ]
  }]
}
```

## 5. エラーハンドリング

| エラー種別 | 対処方法 |
|---|---|
| GA4 APIレート制限超過 | エクスポネンシャルバックオフでリトライ、警告ログ出力、次サイトへスキップ |
| GA4 認証失敗 | エラーログ出力、管理者アラート送信、バッチ処理を中断 |
| メール配信失敗 | 最大3回リトライ、`delivery_logs` に `error_message` を記録 |
| LINE配信失敗 | 最大3回リトライ、`delivery_logs` に `error_message` を記録 |
| PDF生成失敗 | エラーログ出力、該当サイトの配信をスキップ、管理者アラート送信 |
| DB接続失敗 | エラーログ出力、バッチ処理を中断、管理者アラート送信 |

## 6. セキュリティ設計

### 6.1 認証

- 管理者ログインはメール + パスワード（bcryptハッシュ化、コストファクター12）
- NextAuth.jsによるセッション管理（HTTP-onlyクッキー）
- セッションは非アクティブ状態が8時間続いた場合に自動タイムアウト

### 6.2 APIセキュリティ

- 全APIルートでセッショントークンの有効性をミドルウェアで検証
- APIレスポンスに認証情報・シークレットを含めない
- 全リクエストパラメータをZodによってバリデーション

### 6.3 認証情報の管理

- 全シークレットは環境変数で管理し、ソースコードにハードコードしない
- GA4サービスアカウントキーファイルはWebアクセス不可ディレクトリに配置
- データベース認証情報は定期的にローテーションする

## 7. テスト計画

| テスト種別 | テスト範囲 | 使用ツール |
|---|---|---|
| ユニットテスト | GA4クライアント、レポート生成、メール / LINE 各モジュール | Jest |
| 結合テスト | テスト用DBを使ったAPIエンドポイント | Jest + Supertest |
| E2Eテスト | 管理画面操作フロー（クライアント登録・サイト登録・手動レポート生成） | Playwright |
| バッチテスト | ステージング環境での月次ジョブ実行 | 手動 / CI |
| 負荷テスト | 100クライアントを対象とした1回のバッチ実行シミュレーション | k6 / Artillery |
