## 1. 機能要件

### 1.1 クライアント管理

| ID | 要件 | 優先度 |
|---|---|---|
| FR-001 | 管理者は新規クライアントを登録できる（会社名・連絡先メール・LINE ID・配信チャネル） | 高 |
| FR-002 | 管理者はクライアント情報を編集できる | 高 |
| FR-003 | 管理者はクライアントを削除（または無効化）できる | 中 |
| FR-004 | 管理者は登録済みクライアントの一覧を確認できる | 高 |
| FR-005 | クライアントごとに配信チャネルを選択できる（メール / LINE / 両方） | 高 |

---

### 1.2 サイト管理

| ID | 要件 | 優先度 |

| FR-012 | 管理者は登録済みサイトを編集・削除できる | 中 |

| FR-022 | 毎月1日にデータ取得を自動実行する | 高 |

| FR-024 | サイトごとのレポート開始日を考慮してデータを取得する | 高 |

## 2. 非機能要件

### 2.1 パフォーマンス

| ID | 要件 | 目標値 |
|---|---|---|
| NFR-001 | クライアント1件あたりのレポート生成時間 | 30秒以内 |
| NFR-002 | 全クライアントのバッチ処理完了時間 | 5分以内 |
| NFR-003 | 管理画面の各ページ読み込み時間 | 3秒以内 |

### 2.2 信頼性・可用性

| ID | 要件 | 目標値 |
|---|---|---|
| NFR-010 | システム稼働率 | 月間99.5%以上 |
| NFR-011 | 配信成功率 | 99%以上 |
| NFR-012 | ジョブ失敗時のリトライ | 最大3回 |

### 2.3 セキュリティ

- 全通信はHTTPS / TLSで暗号化する
- APIキー・認証情報は環境変数で管理し、ソースコードに含めない
- 管理者パスワードはbcryptでハッシュ化して保存する
- Google Analytics OAuth2トークンは安全に保存・自動更新する

### 2.4 保守性

- MVCまたは同等のアーキテクチャパターンに従って実装する
- 環境ごとの設定管理（開発 / ステージング / 本番）を行う
- デバッグ・監査のための包括的なロギングを実装する

## 3. 外部インターフェース要件

| インターフェース | 種別 | 説明 |
|---|---|---|
| Google Analytics Data API v1（GA4） | REST API | 月次サイトトラフィック指標の取得 |
| Gmail / SMTPサーバー | SMTP | クライアントへのメールレポート送信 |
| LINE Messaging API | REST API | クライアントへのLINEレポート送信 |
